<div align="center">
  <h2>👨‍💻 Sobre mim</h2>
</div>


Sou um profissional de TI com sólida base em infraestrutura, atualmente focado na **transição de carreira para Desenvolvedor Full-Stack Júnior**.

Minha vivência anterior me proporciona uma visão sistêmica sobre servidores, redes e ambientes corporativos, o que me ajuda a criar softwares pensados não apenas no código, mas também em performance, deploy e escalabilidade.

**Onde estou focando hoje:**
* 💻 **Frontend:** React, TypeScript.
* ⚙️ **Backend:** Java, Kotlin, Node.js.
* 🔌 **Integrações:** Desenvolvimento e consumo de APIs REST.
* 🗄️ **Dados:** PostgreSQL, MongoDB.
* ☁️ **Infra & DevOps:** Docker, Azure, Linux, Windows Server.
* 🧩 **Arquitetura:** Boas práticas com MVC, DDD, SOLID e Clean Architecture.
